# Lista de Tarefas com persistência em JSON

## Lista de tarefas com as seguintes opções:
    - Cadastrar tarefas com ID, NOME e STATUS (***ID e  STATUS são automaticamente implementados***)
    - Remover tarefas pelo ID
    - Marcar tarefas como concluídas
    - Listar tarefas concluídas
    

## Requisitos
    - Ter o python 3.14+ instalado


## Como usar
 1° - Clonar o repositório na sua máquina: `gh repo clone KauanNaves/lista-tarefas`  
 
 2° - Executar o arquivo main: `python main.py`
